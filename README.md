# 🚀 WinOptimize Ultimate v6.1 - MÁXIMO RENDIMIENTO

**WinOptimize Ultimate** es la herramienta definitiva de optimización para Windows 11 y 10, diseñada para llevar tu PC al siguiente nivel con un solo clic. Desarrollado por **FranVi**, este script combina limpiezas profundas con ajustes de registro de nivel profesional y un modo **EXTREME** único en su clase.

> **¡NUEVO en v6.1 ULTIMATE PLUS!** Auto-elevación UAC, Punto de Restauración automático silencioso, limpieza profunda nativa (Cleanmgr), apagado de Cortana y Copilot, vaciado de caché de iconos y un Debloat masivo mejorado.

---

## 🔥 ¿Qué hace volar a tu PC? (Funcionalidades)

### 🛠️ Optimización Estándar (21 Pasos)
1. **Punto de Restauración:** Creación automática silenciosa por seguridad.
2. **Limpieza Total (Cleanmgr):** `%TEMP%`, Windows Update cache, Old Windows, DirectX cache.
3. **Prefetch y Logs:** Limpia cachés y vacía registros de eventos.
4. **Caché de Iconos:** Elimina `.db` para evitar cuelgues de Explorer.
5. **Plan Máximo Rendimiento:** Esquema de energía + timeouts de monitor/disco a 0.
6. **Servicios Desactivados:** DiagTrack, dmwappushservice, SysMain, WerSvc, Webclient, W32Time, Spooler, RemoteRegistry, SSDPSRV.
7. **Cortana y Copilot:** Desactivados completamente desde políticas locales.
8. **Registro de Interfaz:** MenuShowDelay, MinAnimate, TaskbarAnimations, VisualFX.
9. **Prioridad CPU:** Win32PrioritySeparation a 38.
10. **Mantenimiento DISM:** Cleanup de componentes e imagen del sistema.
11. **Red y DNS:** TCP/IP optimizado, DNS de Google (8.8.8.8).
12. **Power Throttling:** Desactivado para máximo rendimiento.
13. **Bing Search:** Desactivado del sistema de búsqueda.
14. **Latencia Multimedia:** NetworkThrottlingIndex y SystemResponsiveness a 0.
15. **PCI Desbloqueado:** Ajustes de energía PCI visibles.
16. **Explorador Optimizado:** LaunchTo, HideIcons, AutoCheckSelect.
17. **Memoria Avanzada:** DisablePagingExecutive, LargeSystemCache.
18. **Indexado Desactivado:** WSearch desactivado.
19. **DNS Google:** Configuración IPv4/IPv6.
20. **Actualizaciones Ajustadas:** Opciones de Windows Update configuradas.
21. **Cache Navegadores:** Limpieza de WebCache.

### ⚡ Modo EXTREME / GAMER (+7 Pasos Extra)
- **GPU HAGS Completo:** Hardware Accelerated GPU Scheduling.
- **Debloat Plus Avanzado:** Array optimizado (Xbox, Maps, FeedbackHub, TikTok, etc.).
- **Telemetría Eliminada:** Tareas programadas desactivadas.
- **Modo Gamer Pro:** GameBar, GameDVR deshabilitados.
- **CPU Extrema:** C-states desactivados.
- **GPU Optimizada:** Ajustes NVIDIA/Intel.
- **Windows Defender Parcial:** (Requiere Tamper Protection apagado manualmente).

## 🛡️ Seguridad Ante Todo
- **Auto-elevación UAC:** Pide permisos automáticamente.
- **Punto de Restauración Integrado:** Fallback rápido si algo falla.
- **Opción de Restaurar (14 Pasos):** La Opción [3] deshace todos los cambios importantes.
- **Logs de Auditoría:** Archivo `.txt` en tu escritorio con cada acción.

---

## 📋 Instrucciones de Uso

1. **Descarga:** Baja el archivo `WinOptimize.bat`.
2. **Ejecución:** Simplemente haz doble clic (pedirá permisos él solo).
3. **Elige tu nivel:**
   - Pulsa `1` para optimización estándar.
   - Pulsa `2` para modo EXTREME/GAMER.
   - Pulsa `3` para revertir cambios.
4. **Reinicia:** ¡Es fundamental!
